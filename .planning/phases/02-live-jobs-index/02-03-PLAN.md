## Phase Goal

**As a** TopFit operator, **I want to** have a fresh, normalised, embedded index of real India/remote tech jobs that one worker refreshes on a schedule without ever wiping it, **so that** search and ranking in later phases work on real, current jobs even when the LLM is unavailable.

<objective>
FND-06: the single LLM gateway in `ranker/llm/` with timeout/retry, per-call logging to `llm_calls`, a monthly budget check (D-10, $5 default), typed structured outputs (no `dict`), a fake provider for tests and an Anthropic provider that is safe with or without a key (D-09). Also creates the `llm_enrichment_cache` table that plan 02-11 uses (D-08 cache by content_hash).

Purpose: every later LLM consumer (enrichment now; rerank, resume parse, agent later) inherits logging, budget and degradation for free.
Output: migration 0003, `ranker/llm/*`, `config/llm_prices.yaml`, tests.
</objective>
