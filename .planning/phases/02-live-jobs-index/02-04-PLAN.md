## Phase Goal

**As a** TopFit operator, **I want to** have a fresh, normalised, embedded index of real India/remote tech jobs that one worker refreshes on a schedule without ever wiping it, **so that** search and ranking in later phases work on real, current jobs even when the LLM is unavailable.

<objective>
Rule slice for "where is this job and who can take it": location (NORM-02), remote eligibility rules (NORM-03 rules half; the LLM fallback for `unknown` is plan 02-11), and the tech/geography scope filter (D-05, D-06). Pure functions over YAML config with table-driven tests. Plan 02-07 wires them into the pipeline so a sampled job shows these fields.

Output: three normaliser modules, three YAML files, tests, ADR 0002.
</objective>
