## Phase Goal

**As a** TopFit operator, **I want to** have a fresh, normalised, embedded index of real India/remote tech jobs that one worker refreshes on a schedule without ever wiping it, **so that** search and ranking in later phases work on real, current jobs even when the LLM is unavailable.

<objective>
D-14/D-16 source completion: the free remote-job APIs (Arbeitnow, RemoteOK, Jobicy) and the Internshala listing-page adapter, all on the 02-07 SourceAdapter contract, so the index reaches the ADR 0001 target of 1500 from free sources. Internshala follows the D-15 scraper rules exactly through a small production `polite.py` helper (a hardened version of the spike's `Politeness`/`check_robots`). Himalayas is skipped with the reason recorded. HN stays in Phase 6 (ING-03).

Purpose: Internshala (~780 listed jobs plus internships, all India) is the largest India-only source after the boards; the APIs add a few dozen remote-eligible jobs.
Output: four adapters, polite fetcher, sources.yaml sections, fixtures, unit + end-to-end tests, ADR 0001 Himalayas line.
</objective>

| T-02-62 | Repudiation / legal | Internshala scraping | mitigate | D-15: honest UA, runtime robots check failing closed, path allow-list regex, 3 s/host spacing, refusal latch with no retry, no login/proxies/UA rotation, listing fields + detail URL only, purge-source tested |
| T-02-63 | Denial of service (to the scraped host) | Internshala page volume | mitigate | max_pages_per_category 20, two runs per day, stop on empty page or first refusal |
