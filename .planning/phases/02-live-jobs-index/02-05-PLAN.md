## Phase Goal

**As a** TopFit operator, **I want to** have a fresh, normalised, embedded index of real India/remote tech jobs that one worker refreshes on a schedule without ever wiping it, **so that** search and ranking in later phases work on real, current jobs even when the LLM is unavailable.

<objective>
Rule slice for "what does this job pay, at what level, for whom": salary parsing + INR conversion (NORM-04, D-12, D-13), seniority and employment-type rules (NORM-05 rules half; LLM fallback in plan 02-12), and company-name normalisation (NORM-07 pure half; the `companies` table is created in plan 02-07 and filled by the pipeline in plan 02-08). Pure functions with table-driven and property tests. (MVP note: wiring into the ingest pipeline happens in plan 02-08, which completes the Remotive vertical slice.)

Output: three normaliser modules, `config/fx.yaml`, tests, ADR 0003.
</objective>
