## Phase Goal

**As a** TopFit operator, **I want to** have a fresh, normalised, embedded index of real India/remote tech jobs that one worker refreshes on a schedule without ever wiping it, **so that** search and ranking in later phases work on real, current jobs even when the LLM is unavailable.

First half of the Remotive end-to-end slice: the jobs-index schema (migration 0004), the SourceAdapter plugin contract (ING-04), the retrying HTTP client (ING-07) that Adzuna and Greenhouse/Lever reuse, and the Remotive adapter that turns the live feed into RawJob items. Plan 02-08 completes the slice (normalize_job, hashing, idempotent upsert, run lifecycle, `ranker ingest` CLI); the normaliser rules from 02-04/05/06 are wired there. </objective>
