## Phase Goal

**As a** TopFit operator, **I want to** have a fresh, normalised, embedded index of real India/remote tech jobs that one worker refreshes on a schedule without ever wiping it, **so that** search and ranking in later phases work on real, current jobs even when the LLM is unavailable.

<objective>
First end-to-end ingestion slice: Remotive → scope filter → full normalisation (wiring every rule from plans 02-04/05/06) → content hash → idempotent upsert into `jobs`/`companies` → `ingest_runs` row, triggered by `ranker ingest remotive`. Also defines the SourceAdapter plugin contract (ING-04) and the retrying HTTP client (ING-07) that Adzuna and Greenhouse/Lever reuse. Embedding is added by plan 02-08, expiry by 02-10.

Purpose: after this plan an operator can run one command and see real, normalised jobs and run statistics in Postgres.
Output: migration 0004, source contract + registry, Remotive adapter, HTTP client, normalize_job, hashing, store/pipeline, CLI `ingest`.
</objective>
