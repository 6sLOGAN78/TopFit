## Phase Goal

**As a** TopFit operator, **I want to** have a fresh, normalised, embedded index of real India/remote tech jobs that one worker refreshes on a schedule without ever wiping it, **so that** search and ranking in later phases work on real, current jobs even when the LLM is unavailable.

(The ROADMAP Phase 2 goal is outcome-shaped rather than user-story-shaped; this story restates it without adding scope, following the Phase 1 precedent.)

<objective>
ING-00: measure the real per-source volume, quota and terms before any source-specific ingestion code is written, and record the source mix, job-count target and the ING-13 (Greenhouse/Lever) decision in ADR 0001. The same owner sitting also approves the new package batch for the phase, which this plan then installs (batched owner actions).

Purpose: D-01/D-02 make the target and the Greenhouse/Lever pull-in depend on measured numbers. Plans 02-10, 02-14 and 02-15 read the ADR's marker lines.
Output: `ranker.spike.sources` CLI + tests, `docs/decisions/0001-sources.md`, `docs/decisions/0001-sources-spike.json`, updated `pyproject.toml`/`uv.lock`.
</objective>
