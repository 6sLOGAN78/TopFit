# 02-19: more per-company ATS board adapters (free, public JSON)

## Why
- Ranker has about 1,850 active jobs. Owner decision 2026-11-28: get more jobs from free public ATS feeds, not freehire, whose paid plan breaks the budget.
- Elip reportedly reads LinkedIn, Indeed and Naukri. All three forbid scraping and have no public API, so they are out under D-15.

## Scraping rules (owner relaxed D-15 on 2026-11-28; this replaces the D-15 text in this plan)
- Use an honest UA.
- robots.txt is advisory: log it, don't block on it.
- At least 1 s between requests to one host.
- Stop a scope on 403/429/challenge page. Never solve CAPTCHAs or Turnstile, never defeat anti-bot challenges, never spoof fingerprints, no rotating proxies, no logged-in scraping.
- SmartRecruiters (`https://api.smartrecruiters.com/v1/companies/{id}/postings`) is back in scope for 02-19.

## Tasks
1. **Endpoint and robots check.** For each ATS, confirm the public endpoint and its robots.txt with one or two live requests (orchestrator-approved probing; honest UA, 1 s spacing). Candidates:
   - Workable: `https://apply.workable.com/api/v3/accounts/{slug}/jobs` (POST) or `https://www.workable.com/api/accounts/{slug}?details=true`.
   - Recruitee: `https://{slug}.recruitee.com/api/offers/`
   - Breezy: `https://{slug}.breezy.hr/json`
   - Personio: `https://{slug}.jobs.personio.de/xml` (XML; parse with stdlib `xml.etree` and defusedxml if it is already a dependency, otherwise guard against entity expansion).
   - Note: Workable's `apply.workable.com/robots.txt` allows all.
2. **Migration 0008.** Widen the `source_boards.ats` CHECK, and extend `Ats` / `ALL_ATS` in `board_registry.py`. Hosts for subdomain ATS must be built from a validated slug only (the existing `checked_url` pattern), never from payload data (SSRF guard).
3. **Adapters.** Model them on `ashby.py`: parse into `RawJob` (title, url, company, location parts, country hint, workplace, employment type including internship, posted_at, salary if present, description). Register each in `sources/__init__.py`. Schedule twice daily in `sources.yaml`, staggered after ashby (22:35, 22:45 … UTC and 10:35, 10:45 …).
4. **Seeds.**
   - Probe India-hiring companies on each ATS: Indian startups and MNCs with India offices. Use about 100 candidate slugs per ATS, 1 s spacing.
   - Keep boards with at least 1 India-located or India-eligible remote job. Add them as seeds with `company_names`.
   - Append probe records to `docs/decisions/0001-sources-spike.json` in the existing record shape, plus `measured_at`.
   - Extend `test_yaml_seeds_match_spike` to the new ATS.
5. **Tests.** Write respx fixture tests per adapter: parsing, a 404 board drop, invalid items counted, and that internship maps to `employment_type`.
