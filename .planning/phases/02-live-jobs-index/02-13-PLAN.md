## Phase Goal

**As a** TopFit operator, **I want to** have a fresh, normalised, embedded index of real India/remote tech jobs that one worker refreshes on a schedule without ever wiping it, **so that** search and ranking in later phases work on real, current jobs even when the LLM is unavailable.

<objective>
Slice: "the index refreshes itself, and an admin can poke it". Connects everything into the running system: ingest/TTL/backlog task handlers, enrichment enqueue after each run, source cron jobs in the leader worker (OPS-02, ING-01 cadence), the admin trigger endpoint (ING-11), config self-check in the image, and container memory limits.

Output: handlers, scheduler registration, admin router, settings, compose changes, tests.
</objective>
