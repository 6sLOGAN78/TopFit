## Phase Goal

**As a** TopFit operator, **I want to** have a fresh, normalised, embedded index of real India/remote tech jobs that one worker refreshes on a schedule without ever wiping it, **so that** search and ranking in later phases work on real, current jobs even when the LLM is unavailable.

<objective>
Slice: "ingested jobs become searchable vectors". Adds the embed pass (SRCH-01) to every ingest run and a backfill CLI, with change-only recomputation (ING-09) built on the upsert's "embedding NULL on change" rule from plan 02-07.

Output: `ranker/embeddings/service.py`, pipeline hook, `ranker embed` CLI command, tests.
</objective>
