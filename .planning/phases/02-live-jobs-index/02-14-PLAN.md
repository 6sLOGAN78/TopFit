## Trust Boundaries

|----------|-------------|
| job text from other sources → discovered slugs → outbound URLs | untrusted strings choose which URLs the worker requests |
| ATS JSON → pipeline | untrusted HTML/text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-49 | Tampering / SSRF | discovered slug in URL | mitigate | strict slug regex, fixed host allow-list (4 hosts), URLs built from constants + validated slug, httpx params for query values; tests reject traversal/query slugs |
| T-02-50 | Denial of service (to ATS hosts / our quota) | discovery probing | mitigate | ≤ 40 probes per run, 1 req/s, weekly cadence, 30-day re-probe for rejected candidates, tenacity backoff on 429/5xx |
| T-02-51 | Tampering | index padding with off-scope jobs (D-02) | mitigate | acceptance threshold N=5 in-scope India/remote-eligible jobs; scope filter at ingest; rejected boards logged with reasons |
| T-02-52 | Tampering (stored XSS later) | Greenhouse entity-escaped HTML, Ashby descriptionHtml | mitigate | description_entity_escaped → html.unescape then nh3 (NORM-01 cleaner); Ashby plain text preferred |
| T-02-53 | Denial of service | one failing board expiring others | mitigate | per-board scopes; failed boards excluded from complete_scopes; per-scope volume guard |
