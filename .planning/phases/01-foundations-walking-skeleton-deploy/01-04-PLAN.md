## Phase Goal

**As a** Ranker developer (and any visitor to the live site), **I want to** start the whole stack with one command and open the HTTPS site to see the API, database/pgvector, embedding-model and cookie checks pass, **so that** memory fit, pgvector version, cold start and log hygiene are proven before any feature work.

<objective>
Package the skeleton into images and make the whole stack start with one command: a multi-stage API image with the embedding model baked in and proven offline, a standalone web image, local Compose files, a Makefile (including the manual `make deploy` fallback), a fully documented `.env.example`, pre-commit hooks and README run instructions.

Purpose: After this plan, `make dev` gives the full local stack with the REAL model (FND-01, FND-05), and the exact images CI will publish exist and are verified locally.
Output: two Dockerfiles + selfcheck, compose.yaml, compose.dev.yaml, Makefile, .env.example (+ guard test), .pre-commit-config.yaml, README.md.
</objective>
