## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| owner laptop -> VM (root, once) | Bootstrap runs as root over SSH |
| executor -> VM | Read-only measurement commands as `deploy` with a passphrase-less key |
| internet -> VM | Public HTTPS service |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-60 | Information disclosure | secrets during setup | mitigate | secrets set via `gh secret set` from files/stdin, never pasted into chat or committed; executor never prints /srv/ranker/.env |
| T-01-61 | Information disclosure | exposed internal ports | mitigate | external `nc` checks prove 5432/8000/3000 are closed; only 22/80/443 open |
| T-01-62 | Spoofing | TLS certificate | mitigate | Caddy/Let's Encrypt cert verified with openssl s_client; DNS checked with dig before first start to avoid rate-limit lockout |
| T-01-63 | Elevation of privilege | passphrase-less ranker_deploy key on the laptop | accept | key is scoped to the `deploy` user on one VM, mode 600 in ~/.ssh, revocable by editing authorized_keys; documented in ADR |
| T-01-64 | Elevation of privilege | root SSH after bootstrap | mitigate | PermitRootLogin prohibit-password (key only) set by bootstrap; ADR notes the follow-up to set it to `no` |
| T-01-65 | Denial of service | public readyz embedding cost | accept | ~ms per call on CPU; rate limiting arrives with SEC-04 in Phase 3 |
</threat_model>
