## Phase Goal

**As a** Ranker developer (and any visitor to the live site), **I want to** start the whole stack with one command and open the HTTPS site to see the API, database/pgvector, embedding-model and cookie checks pass, **so that** memory fit, pgvector version, cold start and log hygiene are proven before any feature work.

<objective>
Deliver the backend half of the walking skeleton as a runnable, tested slice: a uv-managed `ranker` package (flat layout under `backend/`) serving `/api/healthz`, `/api/readyz` (real DB read of the pgvector extension version + model probe) and `/api/session/ping` (signed cookie round-trip), an Alembic baseline migration that creates the `vector` extension, and a stub worker that exits cleanly on SIGTERM.

Purpose: After this plan a developer can run `uv run uvicorn ranker.main:app` against any pgvector PG18 database and get a real readiness report and cookie round-trip. Every later plan (web, logging, images, deploy, CI) builds on these contracts.
Output: backend package, lockfile, migration, worker stub, and a green pytest suite running on testcontainers.
</objective>

<interfaces>
Contracts this plan CREATES (consumed by plans 01-02, 01-03, 01-04, 01-05, 01-06). Names are fixed; do not rename.

Settings (`ranker.settings.Settings`, pydantic-settings BaseSettings, env vars are the upper-case field names, no env_file, extra env vars ignored):
- app_env: Literal["development","test","production"] = "development"
- database_url: str (required; e.g. postgresql+psycopg://ranker:ranker@db:5432/ranker)
- session_secret: SecretStr (required)
- cookie_secure: bool = True
- embedder: Literal["fastembed","fake"] = "fastembed"
- embed_model: str = "BAAI/bge-small-en-v1.5"
- embed_threads: int = 2
- log_level: str = "INFO"
- worker_heartbeat_seconds: float = 30.0
- `get_settings() -> Settings` wrapped in functools.lru_cache (tests call `get_settings.cache_clear()`).

Embeddings (`ranker.embeddings`, re-exported from `ranker/embeddings/__init__.py`):
- `class Embedder(Protocol)`: attribute `dim: int`; method `embed(self, texts: Sequence[str]) -> list[list[float]]`
- `FastEmbedEmbedder(model_name: str, threads: int)` wraps `fastembed.TextEmbedding(model_name=..., threads=...)`; `embed` converts each numpy array with `.tolist()`; `dim = 384`
- `FakeEmbedder(dim: int = 384)` deterministic vectors derived from hashlib.sha256 of each text, no network, no numpy requirement
- `build_embedder(settings: Settings) -> Embedder` picks by `settings.embedder`

App (`ranker.main`):
- `create_app() -> FastAPI` with `docs_url="/api/docs"`, `redoc_url=None`, `openapi_url="/api/openapi.json"`, lifespan, and `app.include_router(api_router, prefix="/api")`
- module-level `app = create_app()` (importing must NOT read settings; settings are read inside lifespan)
- lifespan sets `app.state.settings`, `app.state.engine` (AsyncEngine via `create_async_engine(settings.database_url, pool_size=5, pool_pre_ping=True)`), `app.state.embedder` (Embedder or None if loading raised; built in a thread via `anyio.to_thread.run_sync`); disposes engine on shutdown

HTTP endpoints (all under /api):
- GET /api/healthz -> 200 {"status":"ok"}
- GET /api/readyz -> 200|503 {"status":"ok"|"unavailable","checks":{"db":{"ok":bool},"pgvector":{"ok":bool,"version":str|null,"min":"0.8.3"},"model":{"ok":bool},"embedding":{"ok":bool,"dim":int}}}; exceptions report only `type(exc).__name__`, never the DSN
- GET /api/session/ping -> {"cookie_received": bool}; sets cookie name `rk_ping`, value `URLSafeTimedSerializer(session_secret, salt="rk-ping-v1").dumps({"v":1})`, max_age=3600, path="/api", httponly=True, secure=settings.cookie_secure, samesite="lax"; response header `Cache-Control: no-store`

Worker: `python -m ranker.worker` -> logs events `worker_started`, `worker_heartbeat` (every worker_heartbeat_seconds), `worker_stopped`; SIGTERM/SIGINT -> exit code 0. Does NOT load the embedding model.

Migration: Alembic revision id `"0001"`, `down_revision = None`, upgrade runs `CREATE EXTENSION IF NOT EXISTS vector`, downgrade runs `DROP EXTENSION IF EXISTS vector`. `migrations/env.py` reads the URL from `ranker.settings.get_settings().database_url` (not alembic.ini) and does NOT call `logging.config.fileConfig`.
