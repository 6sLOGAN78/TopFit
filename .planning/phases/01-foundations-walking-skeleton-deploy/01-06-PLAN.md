<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR code -> CI runner | Untrusted PR code runs in CI |
| CI -> GHCR | Publishing public images |
| CI -> production VM | SSH with deploy key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-50 | Elevation of privilege | workflow token permissions | mitigate | top-level `contents: read`; `packages: write` only on images job; images pushed only on main push/dispatch, never on pull_request |
| T-01-51 | Information disclosure | deploy secrets on PRs | mitigate | gate and deploy run only on main; pull_request from forks receives no secrets by GitHub design; secrets passed via step env, key file removed in `if: always()` step |
| T-01-52 | Spoofing | first SSH connection (MITM) | mitigate | DEPLOY_KNOWN_HOSTS secret pins the host key; keyscan fallback emits a warning |
| T-01-53 | Tampering | third-party actions | mitigate | only official actions/* and docker/* and astral-sh/setup-uv at verified major tags; no third-party SSH action |
| T-01-54 | Tampering | broken deploy reaching users | mitigate | migrations before api start in deploy.sh; smoke.sh fails the workflow; deploy concurrency group prevents overlapping deploys; PREVIOUS_IMAGE_TAG recorded for rollback |
| T-01-55 | Information disclosure | public images | mitigate | images contain no secrets (.dockerignore, runtime env only, plan 01-04); offline selfcheck runs on the exact built image |
</threat_model>
