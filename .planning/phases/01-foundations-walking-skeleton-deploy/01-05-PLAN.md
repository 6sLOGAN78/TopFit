<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet -> VM | Only 22/80/443 should be reachable |
| internet -> caddy -> api/web | Untrusted HTTP enters through Caddy only |
| CI runner -> VM (SSH) | Deploy key from GitHub Secrets executes commands as `deploy` |
| server .env -> containers | Secrets injected at runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-20 | Information disclosure | deploy/compose.prod.yaml db | mitigate | no `ports:` on db/api/web/worker; check-prod-ports.sh asserts only caddy publishes (Docker ports bypass ufw) |
| T-01-21 | Elevation of privilege | SSH on VM | mitigate | bootstrap: key-only auth, PasswordAuthentication/KbdInteractive no, PermitRootLogin prohibit-password, ufw 22/80/443 only, unattended-upgrades |
| T-01-22 | Information disclosure | /srv/ranker/.env | mitigate | generated with openssl rand hex secrets, mode 600 owned by deploy, never overwritten, never echoed; never in git |
| T-01-23 | Spoofing | X-Forwarded-* headers | mitigate | Caddy ignores client X-Forwarded-* by default (no trusted_proxies); api reachable only on the Docker network |
| T-01-24 | Information disclosure | access logs | mitigate | no Caddy `log` directive; uvicorn access log disabled in image CMD (plan 01-04) |
| T-01-25 | Tampering | TLS / downgrade | mitigate | Caddy automatic HTTPS with HTTP->HTTPS redirect and HSTS max-age=31536000; smoke.sh asserts the redirect |
| T-01-26 | Elevation of privilege | deploy user in docker group | accept | root-equivalent by design on a single-purpose VM; documented in bootstrap.sh comment and ADR |
| T-01-27 | Denial of service | disk filled by container logs | mitigate | Docker daemon log-driver local with max-size 10m, max-file 5 |
